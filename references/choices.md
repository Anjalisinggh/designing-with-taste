# Choices: a menu to calibrate against, not a default

Read this when picking type, colour or a direction. Warning: if you always take the first option here, you have just built a new monoculture. Derive from the subject first, use this only to check your range, and vary from what you did last time.

## Overused type (avoid as the main voice)

First order: Inter, Geist, Poppins, Roboto, Open Sans, Montserrat, system stack.
Second order (the "tasteful AI" picks): Space Grotesk, DM Sans, Plus Jakarta Sans, Manrope, Outfit, Fraunces, Playfair Display, Instrument Serif, DM Serif Display, Rozha One, Abril Fatface, and JetBrains Mono / IBM Plex Mono used as small labels.

These are fine when a subject truly calls for them, never as the reflex.

## Type by subject feel

Pick the feel from the subject, then a family. These are starting points; look past them.

| Subject feel | Families to consider |
|---|---|
| Street signage, transport, loud | Bungee, Anton, Big Shoulders Display, Barlow Condensed |
| Old print, almanac, government form | Libre Caslon, Old Standard TT, Courier Prime |
| Retro machine, arcade, LED | VT323, Silkscreen, Chivo Mono |
| Warm, handmade, kids | Gluten, Grandstander, Sniglet |
| Precise, scientific, engineering | Red Hat Display, Sora, Chakra Petch |
| Fashion, luxury, cinema | Bodoni Moda, Cormorant, Syne |
| Indian scripts and vernacular | Tiro Devanagari Hindi, Yatra One, Baloo 2, Mukta, Hind |
| Friendly product, quirky | Bricolage Grotesque, Young Serif, Figtree |

One or two families. If two, make them clearly different, each with a single job.

## How to derive colour from the subject

Do not pick a palette from a list. Pull it from objects in the subject's world, then name each hex by its source:
- A chai shop: steel tumbler grey, masala brown, cardamom green, newspaper wrap off-white
- A cricket app: pitch clay, sight-screen white, ball red, scoreboard green
- A Mumbai rickshaw: hood black, body yellow, mudguard green, meter LED red
- A hospital booking flow: calm and clinical, one clear signal colour for the action, nothing decorative

Then check: one dominant, one accent with a job, enough contrast, and not one of the converged combos in SKILL.md.

## Layout ideas that are not the template

- The product itself, running live, as the hero
- Content set as an object from the subject: ticket, receipt, form, scorecard, label, menu card
- One huge element on the first screen, everything else small and dense
- Split screen where one side is real content and the other is the tool
- A numbered list only when the content is truly a sequence
- Elements rotated a few degrees like stickers or stamps, used once

## Signature moments

Pick one, tied to the subject:
- A sound on one key action (horn, stamp, click)
- A cursor or pointer that becomes an object from the theme
- A meter or counter that responds to scroll or input
- Text that prints in like a receipt or ticket machine
- A stamp that lands on the page when a form is submitted
