# Landing page design

- **Point of view:** a blind tea-tasting counter. Samples sit in a row as numbered cups, graded without knowing which is which.
- **Dials:** boldness 6, motion 3, density 4.
- **Colours:** tile #EDF1EF (ground, cool, never cream), porcelain #FFFFFF (sample frames), ink #22262A (text), muted #56616B, broker's blue pencil #2350B8 (actions and grading marks only), tea liquor #C68A12 (cup number discs only).
- **Type:** Bricolage Grotesque 800 for display, Atkinson Hyperlegible for body. Sentence case everywhere.
- **Layout:** left aligned. The headline sits beside the intro, and the taste test starts on the first screen. Numbered steps only for the real build sequence.
- **The one bold thing:** the blind taste test. Pick a cup, then a blue pencil circle draws around the one made with the skill.
- **Banned here:** cream with serif and terracotta, ALL CAPS eyebrows, arrows on buttons, middots in copy, invented stats, any mention of the agent vendor.
